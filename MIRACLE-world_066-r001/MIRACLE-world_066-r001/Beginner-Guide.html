Start with five small tasks

  1. Play. Save one screenshot and explain two controls and the goal.
  2. Choose one character, background, object or sound. Explain its job.
  3. Generate it, revise the prompt once and save both attempts.
  4. Log the actual dates, exact tool/model, full prompts, settings, reference links, output links and version filenames. Explain which version you prefer.
  5. Test again. Record one successful test or a problem with steps to repeat it. Request teacher review.
